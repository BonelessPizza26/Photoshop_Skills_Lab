Creating a new document

  1. Go to File › New (Ctrl+N).
  2. Pick a preset at the top (Print, Web, Mobile, Photo…) or type your own size.
  3. Set the Width and Height and the units (pixels, mm, cm).
  4. Set the Resolution: 72 for screen, 300 for print.
  5. Choose the Colour Mode: RGB for screen, CMYK for print.
  6. Click Create.
TipOpening a photo instead? Use File › Open (Ctrl+O) or just drag the photo onto Photoshop.
An A4 page at 300 ppi is 2480 × 3508 pixels. Size in pixels = size in inches × ppi. Choosing the right size before you start avoids blurry, stretched work later. Also look at Artboards – they let you design several screens or sizes in one file.

Saving & exporting

Keep a PSD so you can carry on editing, then export a copy as a JPEG or PNG to share.

1. Save your PSD

File › Save As (Shift+Ctrl+S) and pick Photoshop (.PSD). This keeps every layer, so it’s your “master” file.

2. Export a copy

Use File › Export › Export As to make a JPEG or PNG for the web, social media, email or your portfolio.

Printing?

Use File › Save a Copy › Photoshop PDF when sending work to a printer or uploading print work.

How to use Export As

This is a working copy of Photoshop’s Export As window. Click a step to highlight that setting, then try changing it and watch the preview and file size update.

  1. Finish your design and save the PSD first, so you never lose your layers.
  2. Go to File › Export › Export As…
    Shortcut: Alt+Shift+Ctrl+W (Mac: ⌥+Shift+⌘+W)
  3. Under File Settings, choose the Format: JPG or PNG.
  4. JPG: set the Quality. 60–90% keeps it looking good with a small file.
  5. PNG: tick Transparency to keep a see-through background (great for logos).
  6. Set the Image Size, e.g. 1080 px wide for Instagram. Width and height stay linked so nothing stretches.
  7. Leave Convert to sRGB ticked so colours look right on screens.
  8. Check the preview and file size (bottom left of the preview).
  9. Click Export, choose a folder and give the file a clear name, e.g. khan_poster_v1.jpg.

JPEG or PNG?

Both are images, but they work in very different ways. Choose the right one for the job.

JPEG (.jpg)

Short for Joint Photographic Experts Group. Made for photographs.

Compression
Lossy – it throws away detail you’re unlikely to notice, to make the file small.
Transparency
No – transparent areas become a solid colour (usually white).
File size
Small. You choose the quality: lower quality means a smaller file.
Best for
Photos, social media posts, website images, emailing work.
Watch out
Quality drops a little every time you re-save a JPEG. Always edit the PSD, not the JPEG.

PNG (.png)

Short for Portable Network Graphics. Made for graphics.

Compression
Lossless – every single pixel is kept exactly as it was.
Transparency
Yes – see-through backgrounds stay see-through.
File size
Bigger for photos, but small for simple graphics with flat colours.
Best for
Logos, icons, stickers, text, screenshots, anything with a transparent background.
Watch out
A large photo saved as PNG can be 5–10× bigger than a JPEG.
